# Oracle Autopsy demo — style brief (Bang Motion Hukum #3) + rundown

Theme: Oracle Autopsy, an honesty-first NSE backtester. Feel: forensic, calm, trustworthy.

Concept candidates (opener-konsep.md):
1. #8 Living number — one balance stays in frame; the evidence behind it keeps changing. **Chosen**: the product's whole job is interrogating one number.
2. #4 Before/after — reported equity vs independent ledger split by a moving divider.
3. #7 Object metaphor — a ledger page inspected, torn and re-stamped.

Fingerprint: living number · 6 beats · claimed balance + self-drawing curve / twin ledger line / verdict card / 8-trial tally + sealed-year curve / random-portfolio band / NO-GO stamp + rewrite · opens on a number counting on a ruled page · closes on "real money" struck out, "paper trading only", wordmark + MIT.

Palette (from the product's own HTML report tokens): paper #f3f2ed (bg), ink #1c2e38 (primary), teal #176d8c (accent), rust #a13925 (fail / invented), green #086355 (pass), highlighter #f2d675 (derived from report --mark #fff0bb, darkened so it reads on paper).

Fonts: Fraunces (display serif, editorial) / IBM Plex Mono (numbers, ledger, tabular).
Emphasis: one form — highlighter swipe, used twice.
Background direction: editorial light + paper & print. Surface: warm paper + ruled ledger lines + two soft teal/rust light blobs + live grain (≥ 2 layers).
Background motion (§7c): #4 live paper grain (offset from t) + #8 ruled lines breathing.
Signature motion: the pen — every line, tick, strike and circle draws itself stroke by stroke (drawing-skill idea; Huashu "pure code drawing"), with a slight ink wobble.
Object render: ink line drawing, one family.
Transitions: page turn (object wipe, once); camera pan / tilt across one continuous ledger world (4 panels); one pull-out to the whole map then dive (special); shot-size changes for emphasis.
Special moment: NO-GO stamp slam with paper shake.
Chart grammar (Huashu t3_finance_chart): axes first, data grows by time, one thing marked per shot, one colour carries the hero, source line on screen, numbers never altered.

All figures are real: out/oracle-report.html (synthetic flat-price bug case) and out/monthly-momentum-report.html (sealed year 2025-11-06 → 2026-11-05). Random baseline percentiles (5/50/95: −35,471 / −4,664 / +37,771; beat 99.9%) were computed after the verdict.
